### Oi, eu sou o Mike 👋

Desenvolvedor full stack na **Elétrica Bahiana**, distribuidora de material elétrico na Bahia e em Sergipe. Construo os sistemas internos da empresa: do banco Oracle do ERP até o app que roda no coletor do armazém.

- 🧰 Portal interno em **React + TypeScript** e API em **FastAPI** ligada ao **Oracle** (ERP Winthor)
- 📦 Controle de estoque de cabos por endereço, telas do ERP no navegador e app Android para coletores
- 🤖 IA aplicada: assistente de orçamentos com **LangGraph + Claude API** e servidores **MCP**
- 🐧 Deploy em **Debian** com systemd, Apache e GitHub Actions
